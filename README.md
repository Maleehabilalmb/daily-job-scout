# Daily Job Scout

Cloud routine that scouts Forward Deployed Engineer and client-facing delivery roles daily at 09:00 PKT.

- `spec.md` — architecture, tech stack, search lanes, run contract.
- `job-scout-progress.md` — the spine: candidate fact sheet, standing decisions, every job ever seen.
- `FDE-CV/` — CV variants read at run time.

The routine runs in the cloud and pushes here. Run `git pull` on the laptop to see the latest beat.
